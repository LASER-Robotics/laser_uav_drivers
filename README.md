# LASER UAV Drivers

> **IMPORTANT:** This package is intended **solely for physical drone installations**. It is **not required** and serves no purpose for the system's simulation mode.

This metapackage aggregates all ROS 2 wrappers designed to interface with the SDKs of supported sensors within the system.

## Currently Compatible Sensors

-   Livox Series
-   RealSense Series

## Packages Included

| Package | Description | Repository |
| :--- | :--- | :--- |
| `livox_ros_driver2` | Contains wrappers for the Livox LiDAR series. | [Link to repo](https://github.com/LASER-Robotics/livox_ros_driver2) |
| `realsense-ros` | Contains wrappers for the Intel RealSense camera series. | [Link to repo](https://github.com/LASER-Robotics/realsense-ros) |
